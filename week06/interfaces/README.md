# Bundled px4_msgs definitions

The `.msg` files PX4 v1.17.0 bridges over uXRCE-DDS by default (every type in its `dds_topics.yaml`, and the types they nest), copied unchanged from [PX4/px4_msgs](https://github.com/PX4/px4_msgs) at tag `v1.17.0` under its BSD 3-Clause license (`px4_msgs/LICENSE`, copyright the PX4 Development Team). `week06` reads them with week05's parser to encode and decode PX4 samples with no ROS installed.
