About

UAV Ground School is coursework you can run, measure, and fork.

UAV Ground School publishes end to end solutions for the UAVs@Berkeley Software Ground School skill boosters. The site and repository cover computer vision for aerial imagery, classical and learned object detection, and a flight controller design with every onboard protocol implemented from the specification and checked against real ArduPilot firmware.

The project exists so students, researchers, and tooling agents can inspect working pipelines instead of incomplete sketches. Every major claim on the showcase is backed by JSON benchmarks, ground truth alignments, or firmware in the loop checks that regenerate from the same code that ships in the repository.

What you will find

  • Week 2: HSV color segmentation with object centers, SUAS shape classification, and drone video mosaicking with loop closure, bundle adjustment, and multi band blending in Python and C++17.
  • Week 3: blob detectors scored against hand checked dots, a classical cone cube and ring detector scored against SAM masks, and a YOLOv8 study that documents split leaks and sliced inference gains.
  • Week 4: a Cube Orange+ airframe design, a pin by pin harness, a design rule checker, and from scratch codecs for MAVLink, DroneCAN, CAN, RTCM, CRSF, SBUS, and DShot.

How the project is licensed

Source code is released under the MIT License. Documentation and showcase pages are part of the same public repository. Prefer the GitHub tree when you need to run commands locally; prefer this site when you need the interactive demos, wiring diagram, or published benchmark tables.

For agent oriented discovery, start at llms.txt. Pages also answer Accept: text/markdown on their canonical URLs.
