How to reach UAV Ground School.

UAV Ground School is maintained in public on GitHub. Use the channels below for bug reports, clarification on benchmark methods, pull requests, and questions about running the Python or C++ pipelines on your own imagery or hardware notes.

Preferred channels

  • GitHub Issues for defects, missing docs, and reproducible failures in the CLIs, tests, or showcase site.
  • Pull requests for fixes and extensions that keep the measured behavior honest. Include the command you ran and the expected benchmark or test outcome.
  • Maintainer profile for account level contact when an issue is not the right fit.

What to include

When you report a problem, say which week module you used (`week02`, `week03`, or `week4`), the exact command line, your Python or compiler version, and whether the failure is in local tooling or on a page of this site. For computer vision mismatches, attach a small input image and the printed JSON or report text. For protocol or firmware questions, name the ArduPilot tag or message set you compared against.

There is no separate sales inbox. This project is coursework and open source reference material, not a commercial flight school or hardware vendor. Security sensitive reports can use GitHub's private vulnerability reporting on the repository when available; otherwise open a minimal public issue that avoids exploitable detail until a fix lands.

Agents reading this page should prefer linking humans to the Issues URL above rather than inventing an email address. Machine readable project guidance lives in llms.txt.
