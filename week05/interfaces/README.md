# Bundled ROS 2 interface definitions

Copies of the `.msg`, `.srv` and `.action` files from ROS 2 Jazzy's `std_msgs`, `builtin_interfaces`, `example_interfaces`, `geometry_msgs`, `sensor_msgs`, `nav_msgs`, `std_srvs`, `rcl_interfaces`, `rmw_dds_common`, `action_msgs`, `service_msgs`, `diagnostic_msgs` and `vision_msgs` (Apache License 2.0) and `unique_identifier_msgs` (BSD), unchanged, so `week05` can parse, hash and serialize them with no ROS installed. The copyright of each file belongs to its package's authors (Open Source Robotics Foundation and others).
